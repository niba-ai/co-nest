# Co-Nest

Schweizer Plattform für Co-Parenting: Menschen mit Kinderwunsch finden andere, mit denen sie
gemeinsam Eltern werden möchten – ohne romantische Beziehung.

**➡️ So stellst du die Website online: [ANLEITUNG.md](ANLEITUNG.md)**

## Funktionen

- Konten mit E-Mail-Bestätigung, Passwort vergessen, Konto löschen
- Profil in 4 Schritten: Über mich, Lebenssituation, Werte & Erziehung, Familie
- Familienmodelle «Halb-halb» und «Nach Mass» mit Betreuungs-Skala
- Rollen: Mutter, Vater, begleitende Bezugsperson; Patchwork / bereits Kinder
- Freiwillige sensible Angaben (Geschlecht, Orientierung, Religion) mit Sichtbarkeits-Einstellung
- Passende Vorschläge mit Übereinstimmung in Prozent und Begründung
- Kontaktanfragen (annehmen / ablehnen)
- Live-Chat nur zwischen bestätigten Kontakten
- Melden und Blockieren
- Profile nur für angemeldete Mitglieder sichtbar; alle Regeln in der Datenbank abgesichert

## Technik

React + Vite · Supabase (Region Zürich) · Hosting z. B. Netlify (Gratis)
